# Sebastián Villalba — SV-SportsScientist.com

Landing profesional desarrollada con **Flask + Plotly** para mostrar servicios, proyectos y una demo visual relacionada al rendimiento deportivo.

## Stack
- Python
- Flask
- Plotly
- HTML
- CSS

## Ejecutar localmente

```bash
pip install -r requirements.txt
python app.py
```

Luego abrir:
`http://127.0.0.1:5000`

## Deploy
Este proyecto está preparado para desplegarse en Render.

## Personalización
Editar:
- `app.py`
- `templates/index.html`
- `static/css/style.css`
